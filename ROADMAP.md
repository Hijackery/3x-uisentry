# Roadmap

Направления, которые делают StackSentry полезнее на реальных серверах. Порядок
не является жёстким обещанием; релизы — по готовности и без регрессий.

## Сейчас (1.x)

- Мониторинг сервера, служб, панелей и VPN-стека.
- API-адаптеры: 3X-UI, Marzban, Marzneshin, PasarGuard, Remnawave, S-UI,
  Hiddify, Outline.
- Кроссплатформенные обновления пакетов.
- Telegram-меню, 2FA, аудит, read-only Mini App, web/root-терминал.
- Адаптивные установщик и меню по ОС/службам/панели.

## Ближайшее

- Больше нативных метрик: Xray stats API, sing-box Clash API, Hysteria2.
- Проверка доступности подписок и клиентских конфигов из панелей.
- Массовые операции с пользователями (только чтение и безопасные действия).
- Экспорт метрик в Prometheus и интеграция с внешним мониторингом.
- Улучшение i18n: единый словарь RU/EN для бота, Mini App и документов.
- Пакеты `.deb`/`.rpm`/Arch и контейнерный образ для установки без исходников.

## Идеи

- Мастер миграции между панелями (экспорт/импорт пользователей).
- Резервное копирование конфигураций панелей с проверкой восстановления.
- Плагины уведомлений (Matrix, ntfy, webhook) помимо Telegram.
- Дежурные расписания и эскалации для алертов.
- Сравнение состояния «до/после» обновления панели.

## Не входит в планы

- Произвольный shell и root-доступ из Telegram.
- Опрос Docker API с root-эквивалентными правами.
- Хранение секретов в браузере или в открытом виде.
- Автоматические действия без подтверждения администратора.
